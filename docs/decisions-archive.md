This file preserves historical wording and evidence, including superseded plans. The current [PRODUCT](PRODUCT.md) and [decision ledger](../DECISIONS.md) govern future work; no archived milestone, feature, pricing plan, platform promise or dependency creates a delivery obligation. Consult this file only for a cited decision or a shipped behavior's history.
