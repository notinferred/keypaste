## Amendments

## What changed

- **Finding the AI tools.** `McpToolSurvey` looks at once for every tool keypaste's catalogue connects on this platform, where `keypaste setup` looks, starting each command it finds with `--version`, and reads a found tool's configuration read-only only when the tool has no problem and the look was not cancelled. Each finding says Connected, Not connected, keypaste can't tell (with the reason) or the tool's problem. Agents looks when it opens and again after each Connect or Disconnect, and stops when it closes.
- **Rows.** `McpClientCards.Build` takes the findings, makes a tool and the agent of its id one row, adds agents whose settings the vault holds, orders the rows and builds Every other agent in Core. `AgentRow` replaces the agent cards. Each named row and Every other agent has a Settings disclosure, an `Expander` with a new theme style from the tokens, holding G.8's `AgentSettingsView`; a tool shown Connected adds Connect again and Disconnect there, and one whose configuration keypaste cannot read adds Disconnect. A row with no name says Every other agent's settings apply and has no Settings, since settings follow names. Rows sit in a collection kept in place, so an open panel keeps its controls, focus and drop-downs while agents attach, ask and leave, and a row kept for its open Settings or pane stays current.
- **Connect.** `ConnectClientViewModel` is one pane per tool, showing the plan core composed and running it only on Run it (D-0333), registering the tool under its own id with `--allow-run --expose **`. One pane is open at a time; while its plan or check runs, every other Connect, Connect again, Disconnect and Close is disabled. The Connect form, its picker, Label and Exposure fields and the "Connect client" button are gone.
- **Waiting for you.** Waiting credential, run and environment requests and a settings change awaiting confirmation are listed by agent and what they ask for, never their reason, each with Show the prompt. The gate exposes a waiting change, and `ApproverActivity.WaitingChanges` carries it. `PromptViewModel.Disarm` and an arming generation let only the latest one-second wait arm a prompt; `WindowApprovalChannel.BringForward` disarms the prompt, restores and raises its window, focuses Deny and starts a new wait. Only `SessionHost` and `AppAuthority.ShowPrompt` reach it, from the person's press in the app; no pipe message does (D-0456).
- **Allowances and history.** Each allowance shows its time left over a bar with End, and End all sits in the heading (D-0330). Waiting rows and allowances update in place, so Show the prompt and End are the same buttons as they count down. Since you unlocked and History are unchanged (D-0331, D-0374).
- **Shell.** The sidebar's Agents count and "Answering agents · N waiting" include a waiting settings change. The shell's `Tools` setting supplies the survey, so tests look for no tools unless they give some.
- **Settings panel.** Its Limits row and "Add a row" row wrap, so the panel fits inside Agents' table at the 960 px minimum.
- **Frames on the runners.** dev.yml's class job sets `KEYPASTE_SCREENS_OUT` and uploads `screens-<os>`, so `ScreenRenderer` draws on all three runners; the keypaste-design skill names the route. Agents' frames are `20-agents`, `21-agents-full`, `24-agents-connect`, `25-agents-wide`, `27-agents-settings-open`, `27-agents-settings-narrow`, `28-agents-quiet` and `29-agents-narrow`. Reviewing them against BRAND and the keypaste-design skill tightened the rows, put a wrapped status's dot on its first line and set ids and flags in mono.
- **Driver and gates.** AppDriver gains `tools`, `connect <tool>`, `connect-remove` and `show-prompt`, and `revoke` presses End. `verify-connect-client.sh` connects and disconnects each tool by its row and checks `tools` before and after; `verify-agent-activity.sh` has a show-prompt phase.
- **Documents.** DECISIONS gains D-0455 and D-0456 and amends D-0326, D-0330 and D-0380. THREATS amends T-2, T-11, T-36 and T-40, and SECURITY follows. ARCHITECTURE's processes paragraph and Clients row, `docs/design/README.md`'s Agents section, `docs/approvals.md`, `docs/mcp-setup.md`, `docs/desktop.md` (Agents and manual checks 13, 48 and 56), `docs/policy.md` and FEATURES' End and Show the prompt line follow the screen.
