- **The matcher** (`Core/Browser/`, D-0617, D-0618). `PublicSuffixList` takes a domain name's registrable domain by the list's own algorithm. `WebOrigin` reads a URL as its scheme, lowercase ASCII host and port, and names it as `scheme://host:port` with its site, the registrable domain or an IP address or `localhost` itself. `LoginLookup` reads the extension's `url`, `submitUrl` and `httpAuth`, refuses the request with a `LookupRefusal`, or says whether an item's URL or `KP2A_URL` field matches, whether the form posts to another site and whether the fill is asked about every time. Nothing in it uses a package or the network.

## Limits and follow-ups

- **Single-label names other than `localhost`**, such as `http://router/` or `https://nas/`, get no logins: the list's default rule makes each a public suffix (D-0618). An item for such a host needs a fully qualified name, such as `nas.home.arpa`. The founder may want a narrower rule for them.
- **An item's host written in Unicode**, such as `bücher.de`, matches nothing until it is written as `xn--bcher-kva.de`, since keypaste converts no name at run time (D-0618).
- **A form posting over `http` within the page's registrable domain** is not asked about as another site; the row names only another registrable domain, and the page's own scheme still decides whether the fill is asked about every time.
- **A quoted exact URL** is honoured in the item's URL field as well as in `KP2A_URL` fields, where KeePassXC honours it only in the latter.
- **An IPv4-mapped IPv6 address** is compared as `System.Uri` writes it, which can differ from a browser's form of the same address, so such an item can fail to match.
- **The list ages.** A hosting platform added to the list after the vendored copy counts as one site with its tenants until `update-public-suffix.sh` refreshes it; a release refuses a copy more than 60 days old (D-0616).
- No front end calls the matcher yet: 8.3a2 serves `get-logins` with it, and 8.3a3 proves it in real browsers.
