# 8.1f — Fork and simplify the extension

Completed 2026-11-14 on `t6-extension`, source only.

## Amendments

- **What to strip**, by the founder's direction of 2026-11-14: by the eight design principles of Apple's Human Interface Guidelines, which [DESIGN-PRINCIPLES](../DESIGN-PRINCIPLES.md) adopts, with the cuts left to Claude and approved before the work. Purpose keeps pairing, the field icon and its list of logins, the fill, a keyboard shortcut, the context menu's fill and the toolbar popup. Simplicity and Responsibility remove what keypaste refuses or does not offer: saving and updating logins from a page, the password generator, TOTP, custom and string fields, passkeys, HTTP authentication, several databases, the settings keypaste decides, managed policy, the getting-started page and the permissions only those used. Craft and Familiarity replace Bootstrap and Fork Awesome with keypaste's palette, type and Lucide icons, and KeePassXC's artwork with keypaste's mark. The translations go, leaving English as the app has, which weighs against Flexibility.
- **Test IDs from test keys.** A Chromium extension's ID follows from its manifest key, so 8.1e's placeholders could never load. Two throwaway public keys in `extension/test-keys/`, whose private halves were never written, give the Chrome and Edge test IDs `BrowserIdentity.cs` now names; the Chromium build carries the Chrome one as its key. H-0029 still supplies the stores' IDs.
- **Connect waits for keypaste.** Upstream sealed a pairing request before its key exchange had answered when Connect was pressed as the browser started keypaste, and gave up without asking; the fork waits for the exchange, and the gate presses Connect at once to hold it.
- **A relative program refused.** The gate first named keypaste by a relative path, which no browser starts; `BrowserHosts` now refuses one.

## Limits and follow-ups

- **Not in a store.** The IDs are test IDs until H-0029, and 8.1g publishes. The Chrome Web Store may refuse a package whose manifest carries a `key`, so 8.1g's Chromium package may need it removed.
- **Nothing fills yet.** keypaste refuses every fill until 8.3a2, and a fill in a real browser is 8.3a3's.
- **Unseen by a person.** No one has looked at the restyled popup, list and page, at 200% zoom or with a screen reader; the gate reads their text.
- **The fork's own tests** run in Chromium only, as upstream's do.
- **Edge** is not run; it loads the Chromium build, under the Chrome test ID when unpacked.
- **Firefox's slow-script warning** was logged once, in `background/client.js`, on a run whose pairing failed for the gate's own reason; it did not recur in the passing runs, which print no logs.
- **Code names** such as `kpxc*` and `keepass.js` stay upstream's, to keep the fork comparable.
