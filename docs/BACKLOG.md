# Feature backlog

These are retained feature ideas, not discarded features or promises for the first release. [PRODUCT](PRODUCT.md) owns accepted scope, [ROADMAP](../ROADMAP.md) the milestones of committed work and [STEPS](STEPS.md) its tasks. The features below remain available for future selection. Moving an idea here does not implement it or establish a future release. Select an item only for a concrete unmet user need, then define its scope and verifier in STEPS. Historical IDs locate previous proposals in Git; their old dependencies and commercial promises no longer bind the plan.

## Features for later consideration

| Option | Why it is outside the current product tracks / what would justify it | Previous work IDs |
|---|---|---|
| Browser save, update and passkeys | Filling a login (8.1, 8.3a) is committed to T6. Saving or updating from a page and passkeys each need their own origin-verification and interoperable design. | 8.2a/b, 8.3b–e, 8.4a/b, 8.5a/b |
| Cross-entry references | Same-entry placeholders fill in since P.3b1; `{REF:}` references to another entry (P.3b2) need their own exposure and audit rules. Auto-Type's sequences resolve in Core (P.4a1), and typing them is an option below. | P.3b2 |
| Multiple simultaneous vaults and auto-open | Recent-vault selection already exists. Add concurrent sessions only when needed, with separate locks and exposure scopes. | P.2 |
| Privacy-preserving breach checks | Local password health is in Recommendations (V.9). A remote check is a separate capability with its own privacy design. | P.8 |
| Deleting old backups after an access change | Copies taken before a password or keyfile change still open with the old credentials; `access` names them and routine pruning removes them over time. A delete verb is destructive and needs its own refusals and tests; reconsider when a person needs to close that exposure at once. | V.1a2 |
| Broader cipher/KDF controls and legacy formats | Preserve supported data now; expand advertised compatibility only with fixtures, migration safety and an identified unsupported vault. | P.3a, P.7a/b |
| Encrypted file sharing | Merging a synced file's changes (1.4a/b) is committed to T6, share links for one field or login exist (D-0357), and T8 shares a project's secrets through an end-to-end relay (D-0400). | Drop relay for files | Share links for one field or login exist (D-0357); a relay for files adds hosting and untrusted downloads. Reconsider only after file sharing demonstrates demand; old size, retention and free-service promises are withdrawn. | 5.2a–c, 5.4b, 5.7, H.7–H.10, R.2 |
| External delegation dashboard and provider rotation | Cannot infer downstream rights from a vault entry or log reader. Prove one provider's observable/revocable actions before adding a dashboard. | 6.1, 6.2, S.3 |
| Rotation from the server | A team project with server access (T11) could have the server rotate its values at their issuers. Each provider's rotation is its own integration; reconsider once T11 works and a provider is named. | — |
| SSH and Linux Secret Service | Distinct local protocols and lock-lifecycle obligations; select a named consumer and prove it before exposing vault access. | 9.3a/b, P.5 |
| Phone and web vault clients | A keypaste phone app is the later option for reaching a cloud vault (D-0408); KeePass phone apps reach a local vault through file sync. Separate interaction, delivery and security boundaries. Third-party KDBX compatibility does not establish a keypaste client; no mobile framework or browser runtime is selected by this backlog. | M.1–M.3, W.1–W.2c |
| More architectures | The macOS arm64 desktop joins the first desktop release (STEPS T5). Intel macOS, Windows ARM64, a Linux arm64 desktop and musl each need a selected target and native installation evidence. | 3.9a–d |
| GitHub Release mirrors | Homebrew, Scoop and winget are committed for 1.0.0, once its bytes are published (3.7a–c). A mirror is a separate channel, though the MCP Registry's hosting rule may require a copy of one file (G.6c). The current download origin remains authoritative. | — |
| Fleet deployment and service scale | No operated service or fleet requirement establishes these needs today. Measure a real bottleneck or deployment request first. | S.1, S.2, S.4, S.5 |
| Notes and the commands in them kept private | People keep private notes on an item: connection commands, where its keys live. A note reaches an agent only as its item's one approved field (`Core/Approval/CredentialFields.cs`), but the item pane shows it in plain text, and structuring notes has meant extra fields: the notes check moves `KEY=value` and `export` lines into fields, Database and Server add a `Host` field, and a project needs env-named fields. Ways found on 2026-10-31: hide notes until revealed, stop offering to split command lines into fields, give the templates no extra fields, and have the prompt say that the whole note goes to the agent. Deferred by the founder on 2026-10-31; reconsider when the founder picks a behaviour. | — |
| Apple conventions DESIGN overrides | The audit of 2026-10-31 (D-0682) found these where DESIGN wins: menus in title case, a selected row filled with the accent, the system's accent colour, font and SF Symbols, an app icon drawn as unmasked square layers for macOS 26, and the search field at the toolbar's trailing edge. Reconsider when the founder revisits DESIGN. | — |

## Smaller possibilities

| Idea | Boundary for reconsideration |
|---|---|
| A read-only vault for verbs that never save | `VaultSession.Open` could hand its callback a vault with no save, so a save without the vault's claim would not compile and `SavingVerbSourceRulesTests`' tracer could go ([K.7](steps/K.7.md)). Reconsider when Core's `Vault` API is next reshaped; it changes the type about 16 verbs and Core's helpers take. |
| The crash-report code in its own project | Its rules about single files (`CrashSourceRulesTests`) could become one project's ban list if `Core/CrashReports/` stood alone; Core's settings and home name it today ([K.7](steps/K.7.md)). Reconsider if those rules grow or a false pass is found. |
| A clean inherited environment | `run --no-inherit` may solve specific tool needs; `env diff` and `--json` output already exist. Avoid silently skipping unusable values. |
| Shell/direnv integration or stopping launched programs on lock | Ordinary environments are copied into processes. Any convenience must state descendant exposure and cannot promise to revoke delivered credentials. |
| Secret rotation reminders and deliberate history removal | Reminders do not rotate a provider credential; purging a leaked value is explicit and cannot erase existing copies or backups. |
| Command palette and additional generator recipes | Add when they improve an observed frequent task; existing CLI recipe controls are not proof of desktop controls. |
| Unusual-request notices | Agents' settings are kept and edited in the vault since G.8; a notice that an agent's requests look unusual is not authorization. Avoid automatic broadening, circular unlock rules or inferred trust from a client label. |
| Git secret hooks and conflict guidance | Potential project tooling; a warning or file-sync guide does not implement merge or guarantee secret removal from history. |
| Extra vulnerability channel, reproducible builds, independent review and bounty | Useful trust work when operationally supported. Keep the working private contact and current provenance checks; do not claim review or reproducibility from a draft page. |
| Repository rulesets and fork-CI observation | Administrative improvements may be selected separately. A fixture or policy document is not an observation of a real fork run. Former K.4/K.5. |
| Windows clipboard-history observation | The documented residual remains. A real-machine observation, former 1.5a, can establish only the tested platform behavior. |
| Windows Hello on a real machine, former 4.10c (H-0025) | No CI runner has Windows Hello (T-44). On Windows 10 or 11 with it set up, the app's package from [4.10a](steps/4.10a.md): unlock and answer Windows Hello, lock, resume with it; the prompt in front each time, a cancelled prompt opening nothing, the PIN working, `keypaste lock` then asking for the master password, and a YubiKey vault resumed with it asking for the touch. Record the Windows version, method and commit in 4.10a's limits; a published claim waits for it (D-0557). |
| A physical YubiKey, former P.1b (H-0026) | No CI runner has a YubiKey (T-37); [P.1a](steps/P.1a.md) ran against a software key. Record the platform, key model and firmware, KeePassXC version and commit in P.1a's limits. |
| Consent-based launch notifications and educational material | The existing signup promise requires confirmation before sending. Double opt-in/unsubscribe, a public demo vault, articles and talks require a selected audience and separate sending authorization. Former 5.6, 3.11. |
| Upstream interoperability fixes | Contribute a reproducible format defect when one is found; keep required attribution and interoperability evidence. |
| Attachment edits from a terminal while the app or `keypaste approve` holds the vault | `keypaste attachment add`, `replace` and `rm` are refused then (D-0535): D-0464's terminal edit carries at most 64 KiB, and the app's own screen edits attachments (V.8b). Reconsider when a person needs them from a terminal while the vault is unlocked; the request would carry up to 5 MiB of plaintext over the pipe and needs its own prompt and limit. |
| A native Wayland backend for the Linux app | The app runs under X11 or XWayland, so a Wayland desktop without XWayland cannot start it; it stays so by founder decision 2026-10-22. Reconsider when Avalonia ships a stable Wayland backend. |
| Auto-Type typing | keypaste resolves an item's Auto-Type sequence and window associations in Core (P.4a1, D-0604 to D-0607) and types none of it: typing into another app's window on Windows, macOS and X11, the global shortcut and its chooser left 1.0.0 (D-0632), with the design the founder approved (D-0547) and these rows' detail in Git at `ce84d3fe`. Browser fill serves web logins. Reconsider when people ask for logins outside the browser, such as desktop apps and remote sessions, and a typing engine can be written or sourced that passes review under PRODUCT §3.9. | P.4a2, P.4a3, P.4a4, P.4a5, P.4b1, P.4b2 |
| `{PICKCHARS}` in Auto-Type | A sequence holding it is refused (D-0604): KeePassXC types the characters a person picks from a field, and keypaste has no picker. Reconsider when a sign-in that asks for chosen characters of a password is named; the picker draws a secret's characters and needs its own drawing and refusal rules. |
| Editing Auto-Type settings | keypaste reads the sequences, window associations and switches KeePass and KeePassXC write and writes none (D-0605). Reconsider when someone who sets up items in keypaste needs one; a new writer needs its own KeePassXC gate. |
| The wordmark inside the unlocked app | The sidebar's "keypaste." wordmark takes room in the unlocked app that its places could use (founder, 2026-11-01); DESIGN has the sidebar carry it. Reconsider when the founder takes it up, with DESIGN's rule amended. |
| Closing into the menu bar or tray by default | Closing the window locks and leaves the app in the menu bar or tray on Windows and macOS (D-0385), and Apple's guidelines ask that people, not the app, put an icon there and that nothing rely on it. Reconsider when people are seen losing the app after closing it, by asking at the first close. |
| A relock opened by Touch ID or Windows Hello | A close or an idle lock asks for the master password again, which a person who closes a window or steps away meets often. Reconsider once macOS quick unlock (4.10b) lands, for a relock within a window the person sets. |

| Desktop acts for the menus and the generator | Driving the app on the founder's Mac through System Events found what headless tests could not (a stale build, AppKit's own View item, focus after the open panel), but clicks by screen position are slow and brittle because Avalonia names no element for macOS accessibility. | The icon script on Python 3.9 | `scripts/lucide-to-axaml.py` calls `Path.write_text(..., newline="\n")`, which Python 3.9, the founder's Mac's, refuses; V.12 regenerated `Icons.axaml` through a wrapper. Reconsider at the next icon added. |
| Properties for the placeholders, the Public Suffix List matcher and the merge | [K.11](steps/K.11.md) tested TOML and CSV by property with FsCheck, whose code came to about the length of the examples it replaced, and measured these three suites. Reconsider one when it has a defect its examples missed. |
