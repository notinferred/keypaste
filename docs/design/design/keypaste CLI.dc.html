keypastecli · terminal design

The CLI follows the same rules as the app. Amber marks what needs you: prompts, active grants, the cursor. Green means done, red means refused, and grey is everything else. Output is 80 columns wide, pipes cleanly (--json), and never prints a value unless you ask with --reveal.

keypaste --help
keypaste 1.0.0 · secrets for developers and their agents
USAGE
keypaste <command> [flags]
SECRETS
get print a reference, or the value with --reveal
set create or update a secret
run run a command with secrets in its environment
env import, export and diff .env profiles
AGENTS
mcp serve the MCP server over stdio or a socket
grants list or revoke time-boxed access
token create scoped, inject-only tokens
log show the signed activity log
VAULT
import open a .kdbx and keep it in sync
share create an encrypted, expiring link
lock lock now and pause all agents
