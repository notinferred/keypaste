One place for all of it

Each of these is a separate product somewhere else. Here they are parts of one.

CLI · BetaApp · Building

Every login, where you expect it.

Logins with a username, password and URL, filed in groups, with search, copy and a generator. They live in the KeePass format, so KeePassXC opens the same file.

The desktop app
Beta

Your project's secrets, without the .env file.

A project's variables live in your vault. One command puts them into one program's environment, and nothing is written to disk.

Project environments
~/project
keypaste env pull dev            # imports ./.env
keypaste run dev -- npm start    # nothing on disk
Terminal · BetaApp · Building

AI agents ask. You answer.

An agent asks for one field. You see who is asking and why, and you approve or deny that request. Every request is logged locally, granted or refused.

The goal: ready for an enterprise
