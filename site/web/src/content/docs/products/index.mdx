keypaste is one product built in pieces around one idea: your secrets stay in the KeePass file you already own, and nothing gets a value without your answer. Each page below explains what a piece does, how it works and where it stands.

**Beta** means a published download, pre-1.0. **Building** means it is in the source and not downloadable yet. **Planned** means it is committed in the [roadmap](https://github.com/notinferred/keypaste/blob/main/ROADMAP.md), which owns the order of the work. Labels change when a release ships.

<ProductTable />

## What stays out

- A server that can read your personal vault. Team projects use a relay that stores only ciphertext, unless a team chooses server access for a project.
- Phone and web vault apps. KeePassium, Strongbox and KeePassDX open a local vault.
- PKI, KMS, privileged-access management and dynamic secrets.

The [vision](/vision/) explains where these pieces lead.
