keypaste is one access manager where there are usually several products: a password manager for logins, a secrets platform for projects, something for CI and something for AI agents. It is built in pieces around one idea: your secrets stay in a KeePass file you own, and nothing gets a value without your answer. Each page below explains what a piece does, how it works and where it stands.

Labels change when a release ships, and the [roadmap](https://github.com/notinferred/keypaste/blob/main/ROADMAP.md) owns the order of the work.

<ProductGroups />

## What stays out

- A server that can read your personal vault. Team projects use a relay that stores only ciphertext, unless a team chooses server access for a project.
- Phone and web vault apps. KeePassium, Strongbox and KeePassDX open a local vault.
- PKI, KMS, privileged-access management and dynamic secrets.

The [vision](/vision/) explains where these pieces lead.
