# on the same principle: the vendored code wraps every one of these probes in a try/catch and
# treats failure as "feature unavailable", which is the state NativeAOT puts it in permanently.
# DECISIONS.md D-0040 records the reasoning and the six gates that were run against real AOT
# binaries to confirm it, including a KDBX written by the AOT binary opening in real KeePassXC.
#
#   SimpleStat.cs      Mono.Posix probing, to preserve Unix owner and mode across a vault save.
#                      GetTypes() returns false under AOT, Get() then returns null, and
#                      FileTransactionEx.cs:269 only calls Set() when non-null. The vault is
#                      written either way; only the permission copy is skipped, which is already
#                      what happens on any machine without Mono.Posix installed - that is, all
#                      of them, since .NET Core.
#   NativeLib.cs       ProcessArchitecture probing. Falls back to IntPtr.Size at :124. Only feeds
#                      the KeePassLibN native-library loader, which keypaste does not ship.
#   IOConnection.cs    HttpWebRequest internals on remote-vault paths. keypaste opens local files
#                      only; nothing reaches IocStream over HTTP.
#
# No entry may name src/. The script fails on that separately and unconditionally.

# which the diff correctly reports as a failure rather than a pass.
